# Self-Study AI V1.0 正式版定义

## 1. 正式版不是功能冻结

V1.0的含义不是停止演化，而是稳定以下长期契约：

1. 每个学习目标拥有独立身份、会话、Context和数据边界；
2. 学习计划服从用户真实时间预算；
3. 微习惯负责启动，评估和作品负责证明能力；
4. AI辅助必须逐步撤除，而不是制造永久依赖；
5. 所有重要写入可追踪、可备份、可导出、可迁移；
6. 模型、供应商和UI可以替换，学习资产与责任链长期保留。

## 2. 正式产品闭环

```text
目标提出
→ 建立一对一契约
→ 诊断基础与行为条件
→ 编译学习路径
→ 设计微习惯
→ 执行每日最小行动
→ 完成主动练习
→ 修复误解与间隔复习
→ 独立评估
→ 作品验收
→ 沉淀能力证据
→ 正式周复盘
→ 调整一个关键变量
→ 撤除脚手架并迁移
```

## 3. 三种成功不能混淆

### 行为成功

在真实锚点后完成最小行动，并立即庆祝。

### 学习成功

能够解释机制、独立完成任务、延迟保持并迁移到新情境。

### 产品成功

学习者更少依赖AI，却能持续形成更多可验证能力与真实作品。

## 4. 正式版质量门槛

- Schema迁移不可破坏旧数据；
- 每个目标Context严格隔离；
- 重要状态必须持久化，而非只存在前端；
- API密钥不能进入Renderer、日志、Trace和导出；
- 契约、周复盘、评估和作品必须有来源与时间；
- 所有归档必须可恢复；
- 所有不可逆或高风险动作必须经过Harness；
- 应用重启后长程Run安全暂停或恢复；
- 用户可随时完整导出自己的学习资产。

## 5. V1.0后兼容承诺

V1.x优先进行向后兼容增量迁移。未来破坏性数据变更必须：

1. 先创建一致性备份；
2. 记录Schema迁移版本；
3. 验证关键表数量和数据库完整性；
4. 保留JSON/Markdown出口；
5. 在发布说明中明确回滚边界。
