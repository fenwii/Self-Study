# 文档说明

## 适用版本

本手册适用于 **Self-Study AI Electron V1.0.0 正式版**。案例以正式版已经实现的目标独立会话、一对一学习契约、福格行为模型、微习惯、学习路径、任务、知识图谱、误解修复、间隔复习、本地资料库、真实性评估、作品验收、能力证据、周复盘、长程Agent、模型控制面、备份恢复与导出能力为基础。

## 案例数量与结构

本手册包含：

```text
72个完整实践案例
+ 28个快速场景
= 100个实践场景
```

完整案例不是“提示词列表”，而是按照同一生产闭环描述：

```text
真实场景
→ 目标与契约
→ 推荐CHART组合
→ 第一条自然语言
→ 微习惯配方
→ 操作步骤
→ 模块联动
→ 成果与证据
→ 验收标准
→ 异常恢复
→ 可复制对话
```

## 使用原则

1. 案例中的时间、任务与验收是可编辑样例，不应机械照搬。
2. 创建目标时，应使用自己的真实基础、时间预算、工具条件和成果要求。
3. 微习惯只负责让行为发生，不等于已经掌握知识。
4. 能力必须通过独立尝试、延迟保持、迁移任务、作品或外部反馈证明。
5. 医疗、法律、金融、安全、高压电气等高风险领域，案例仅用于教育性学习；真实决策和操作必须由合格专业人士负责。
6. 当前V1.0.0交付为正式版源码包，不等于已经签名的跨平台安装程序。

## 如何选择案例

- **不知道从哪里开始**：先阅读第一篇。
- **有明确学科或职业目标**：进入对应领域篇章。
- **总是无法坚持**：使用第十一篇的行为诊断与恢复案例。
- **已经能稳定学习但依赖AI**：使用“AI依赖修复”与“毕业模式”。
- **管理员或开发者**：重点阅读模型故障、备份恢复和迁移案例。

## 案例中的CHART等级

```text
A：闭环深度，从问答到长期独立学习
B：执行控制，从只读到完整风险、审批与恢复
C：Context深度，从当前消息到终身学习资产
D：治理深度，从最小记录到完整责任链和审计
```

正式长期目标通常使用 `A5+B5+C5+D5`；短时解释或低风险练习可以降低等级，减少不必要复杂度。

# 第一篇：启动与建立个人自学系统

## 案例01：15分钟建立第一个长期学习目标

**适用对象：** 第一次使用 Self-Study AI 的个人学习者  
**建议周期：** 15分钟启动，随后持续迭代  
**推荐组合：** `A5+B5+C5+D5`

**案例目标：** 从一个模糊愿望建立可执行、可验证、可持续的独立学习目标。

### 第一条自然语言

```text
我想系统学习概率论，但目前只有零散概念。请先帮我建立一个长期目标，不要一次塞给我很多任务。
```

### 一对一学习契约建议

每周120分钟；每次25分钟；平衡式教练；证据优先反馈；成功定义为能解释核心概念、独立解决基础题并完成一个小型概率模拟作品。

### 微习惯配方

```text
当我晚饭后打开电脑，我只写下一个今天最想弄懂的概率问题，然后说“已经开始”。
```

### 操作步骤

1. 在左侧新建目标，使用自然语言描述“为什么现在学习、准备达到什么结果、已有基础和可投入时间”。
2. 让系统建立一对一学习契约；确认时间预算、教练方式、自主性目标和复盘节奏。
3. 要求系统进行起点诊断，只问最少的关键问题，不直接生成完整课程。
4. 让系统编译六阶段路径，并只显示当前可执行里程碑。
5. 建立一个30—120秒微习惯配方，完成第一次最小行动。
6. 在当前目标会话中完成第一轮解释或练习，保存误解、任务或能力证据。

### 应形成的学习资产

- 独立目标会话
- 学习契约V1
- 六阶段学习路径
- 首个微习惯配方
- 第一条学习记录

### 验收标准

- [ ] 目标结果可以被外部观察或验收
- [ ] 周计划不超过真实时间预算
- [ ] 第一次会话结束后能明确说出唯一下一步

### 异常与恢复

- 如果目标仍然过大，要求“只保留未来30天能验证的一项能力”。
- 如果系统给出过多任务，直接说“收缩为一个里程碑和一个最小行动”。

### 可复制对话

```text
- 把“学概率论”改写成一个可验证目标。
- 根据我每周120分钟的预算建立学习契约。
- 只告诉我今天唯一下一步。
```

## 案例02：七天学习重启：从停摆到重新发生

**适用对象：** 长期中断、反复开始又放弃的学习者  
**建议周期：** 7天  
**推荐组合：** `A5+B4+C5+D4`

**案例目标：** 不追求七天掌握学科，而是恢复稳定、低摩擦、可继续的学习行为。

### 第一条自然语言

```text
我已经两个月没有学习了。请不要鼓励我硬撑，先诊断为什么行为没有发生，再为我设计七天重启。
```

### 一对一学习契约建议

每周70分钟；每次10分钟；温和反馈；挑战强度1/5；成功定义为七天内至少发生四次最小学习行为，并留下一个可验证的小成果。

### 微习惯配方

```text
当我拿起手机准备刷短视频时，我先打开当前目标，只读一个问题，然后轻轻点头。
```

### 操作步骤

1. 创建“七天学习重启”目标，明确本周只验证行为能否重新发生。
2. 使用行为诊断记录动机、能力、提示可靠性和主要摩擦。
3. 设计不超过30秒的最小行为，并绑定已有稳定锚点。
4. 每天记录 done、partial 或 skipped，同时记录当时的M/A/P条件。
5. 第四天只调整一个变量：缩小行为、换锚点或减少环境准备。
6. 第七天完成正式复盘，决定保留、修改或退役配方。

### 应形成的学习资产

- 行为画像
- 七天Check-in
- 摩擦诊断
- 周复盘
- 下一周唯一调整

### 验收标准

- [ ] 没有使用羞辱或补偿性加量
- [ ] 至少能识别一个真实摩擦来源
- [ ] 七天后最小行为比第一天更容易发生

### 异常与恢复

- 连续两天跳过时，不补做，只将动作缩小一半。
- 锚点不稳定时，换成每天必然发生的事件，而不是增加通知。

### 可复制对话

```text
- 我最近总是无法开始，请按动机、能力、提示分别诊断。
- 把今天的学习缩小到30秒。
- 根据这七天记录，只调整一个变量。
```

## 案例03：30天单项能力训练：从理解到独立作品

**适用对象：** 希望在一个月内形成明确能力的学习者  
**建议周期：** 30天  
**推荐组合：** `A5+B5+C5+D5`

**案例目标：** 围绕一项能力建立路径、练习、证据和最终作品，而不是无边界学习。

### 第一条自然语言

```text
我想在30天内学会用Python清洗CSV并生成分析报告。请建立一条从零到作品的学习链。
```

### 一对一学习契约建议

每周240分钟；每次40分钟；项目式教练；直接反馈；成功定义为独立完成一份带说明、图表和可复现脚本的数据分析作品。

### 微习惯配方

```text
当我上午喝完第一口咖啡，我只打开项目文件并运行一次现有脚本，然后庆祝“环境已经启动”。
```

### 操作步骤

1. 创建目标并把成功定义写成可交付作品。
2. 编译路径：诊断、基础理解、知识地图、主动练习、独立验证、作品交付。
3. 每周只推进一个阶段，阶段完成必须有证据。
4. 将大任务拆成可开始的微习惯，但作品任务仍保留验收量表。
5. 在第3周进行一次无提示评估，识别仍依赖AI的部分。
6. 第4周完成作品验收、延迟复测和一次变体数据迁移。

### 应形成的学习资产

- 学习路径
- 每周任务
- 独立评估
- 最终作品
- 能力证据
- 迁移记录

### 验收标准

- [ ] 作品可由他人复现
- [ ] 关键步骤能脱离AI解释
- [ ] 变换数据后仍能独立完成

### 异常与恢复

- 进度落后时缩小作品范围，不降低核心验收标准。
- 如果一直复制代码，切换为“先写伪代码，再请求最小提示”。

### 可复制对话

```text
- 把30天目标编译成六阶段路径。
- 为作品建立验收量表。
- 现在不要给代码，先检查我的独立方案。
```

## 案例04：零基础进入陌生学科

**适用对象：** 面对完全陌生领域、担心术语过多的学习者  
**建议周期：** 14—30天起步  
**推荐组合：** `A3+B2+C4+D3`

**案例目标：** 建立学科地图、核心问题和基础词汇，不被资料洪流淹没。

### 第一条自然语言

```text
我完全不了解经济学。请先用最少概念让我看见这个学科在解决什么问题。
```

### 一对一学习契约建议

每周150分钟；每次25分钟；苏格拉底式；温和反馈；成功定义为能用自己的话解释五个核心问题并画出一张概念关系图。

### 微习惯配方

```text
当我坐到书桌前，我只写一个“这个学科试图解释什么”的问题。
```

### 操作步骤

1. 建立目标后先做“问题地图”，不直接列完整教材目录。
2. 让系统用演示、降维、体系三种方式解释同一核心概念。
3. 建立最多12个起始知识节点及其前置关系。
4. 每次学习只新增1—3个节点，并登记无法解释的误解。
5. 一周后进行闭卷口头解释或短文评估。
6. 根据评估结果决定继续基础层还是进入应用层。

### 应形成的学习资产

- 问题地图
- 起始知识图谱
- 术语卡片
- 闭卷解释
- 误解清单

### 验收标准

- [ ] 不是背诵定义，而能说明概念解决什么问题
- [ ] 知识图谱节点之间存在明确关系
- [ ] 能识别自己仍不理解之处

### 异常与恢复

- 术语太多时要求“只保留本周必须理解的五个词”。
- 解释仍抽象时要求加入一个生活例子和一个反例。

### 可复制对话

```text
- 请先告诉我这个学科的五个根本问题。
- 用演示、降维、体系三法解释这个概念。
- 请把我刚才的错误理解登记为误解。
```

## 案例05：碎片时间学习系统

**适用对象：** 每天只有零散5—15分钟的忙碌学习者  
**建议周期：** 长期  
**推荐组合：** `A4+B4+C5+D4`

**案例目标：** 在不制造压力的前提下，把碎片时间连接到真实能力与作品。

### 第一条自然语言

```text
我每天只有几个10分钟空档，但想长期学习统计学。请建立碎片时间模式，不要把阅读数量当成果。
```

### 一对一学习契约建议

每周90分钟；每次10分钟；平衡式教练；成功定义为每周完成一次主动回忆、一组小练习和一个微型成果。

### 微习惯配方

```text
当我等电梯或排队时，我只回忆一个公式的含义，而不是打开新资料。
```

### 操作步骤

1. 将目标路径拆成“可在10分钟完成”的学习单元。
2. 区分输入任务、回忆任务、练习任务和作品推进任务。
3. 为不同场景设计不同微习惯：通勤回忆、午休练习、周末作品。
4. 使用复习队列安排到期知识，不在碎片时间引入过多新概念。
5. 每周至少安排一次25分钟整块时间完成综合任务。
6. 周复盘检查碎片行为是否真正转化为证据。

### 应形成的学习资产

- 场景化微习惯
- 10分钟任务队列
- 复习记录
- 每周微型成果
- 能力证据

### 验收标准

- [ ] 碎片任务具有明确结束条件
- [ ] 每周存在至少一项独立输出
- [ ] 输入量没有挤压练习和作品

### 异常与恢复

- 碎片时间只剩阅读时，要求增加“闭屏回忆1分钟”。
- 无法安排整块时间时，进一步缩小作品为可组合的小部件。

### 可复制对话

```text
- 把当前任务改写成10分钟可完成版本。
- 给我一个不需要打开资料的主动回忆任务。
- 检查本周碎片学习是否产生了真实证据。
```

## 案例06：多目标隔离：工作、语言与研究并行

**适用对象：** 同时学习多个领域的用户  
**建议周期：** 长期  
**推荐组合：** `A5+B5+C5+D5`

**案例目标：** 在不同目标间保持会话、资料、任务、行为画像和证据严格隔离。

### 第一条自然语言

```text
我需要同时学习英语、产品管理和论文写作。请分别建立三个目标，避免混在同一个会话里。
```

### 一对一学习契约建议

每个目标建立独立时间预算与成功定义；总周预算不得超过可用时间；每周只设一个主目标。

### 微习惯配方

```text
每个目标使用不同稳定锚点，例如通勤英语、工作后产品复盘、周末论文阅读。
```

### 操作步骤

1. 分别创建三个目标，不在一个目标中创建三个大模块。
2. 为每个目标建立独立契约和微习惯。
3. 将总时间预算分配为主线、维持线和等待线。
4. 切换目标时确认聊天、草稿、路径、资料和证据同步切换。
5. 每周复盘先看总负荷，再分别看目标成果。
6. 暂停低优先级目标时使用暂停或归档，不删除资产。

### 应形成的学习资产

- 三个独立会话
- 独立契约
- 独立行为画像
- 独立资料与证据
- 跨目标时间预算

### 验收标准

- [ ] 任何目标的Context不出现其他目标资料
- [ ] 总计划不超过真实可用时间
- [ ] 暂停目标后可以无损恢复

### 异常与恢复

- 目标过多时设定“本周唯一主线”，其他目标只做最小维护。
- 资料误导入错误目标时归档后重新导入正确目标。

### 可复制对话

```text
- 为这三个方向分别创建目标，不要合并。
- 审查总周预算是否超载。
- 把产品管理暂停两周，但保留全部资产。
```

## 案例07：小学四年级数学：从会做题到会讲清楚

**适用对象：** 小学四年级学生及家长  
**建议周期：** 8周  
**推荐组合：** `A3+B3+C4+D3`

**案例目标：** 理解四则运算、应用题和几何基础，并能用自己的话解释方法。

### 第一条自然语言

```text
我要学习四年级数学。请先找出我真正卡住的地方，不要直接给答案。
```

### 一对一学习契约建议

每周150分钟；每次20分钟；平衡式教练；温和反馈；成功定义为能独立完成题目、说出理由并检查错误。

### 微习惯配方

```text
当我拿出数学本，我只圈出题目中的已知量和所求量，然后说“我开始找关系了”。
```

### 操作步骤

1. 用三道不同类型的小题诊断计算、理解题意和表达过程。
2. 建立“数量关系—运算—图形—检查”知识地图。
3. 每道题先让学生口述思路，再给最小提示。
4. 把错误登记为误解，如“看到一共就一定加法”。
5. 安排间隔复习和变式题，避免只记住原题。

## 案例37：单篇论文深读：从摘要到证据审查

**适用对象：** 研究生、研究人员  
**建议周期：** 2—4小时/篇  
**推荐组合：** `A4+B3+C5+D5`

**案例目标：** 理解论文问题、方法、证据、限制和可迁移价值。

### 第一条自然语言

```text
请帮我深读这篇论文，但不要只做摘要。我要知道它真正证明了什么、没有证明什么。
```

### 一对一学习契约建议

每周2篇；每次60分钟；证据优先；成功定义为能闭卷解释研究问题、方法、关键证据和主要限制。

### 微习惯配方

```text
当我打开论文，我先写“作者试图回答什么问题”。
```

### 操作步骤

1. 导入论文文本或个人摘录，记录来源。
2. 先读标题、摘要、图表和结论，形成预测。
3. 建立问题—方法—数据—结果—限制结构卡。
4. 区分作者主张、数据事实和自己的推断。
5. 提出一个反例或替代解释。
6. 隔日闭卷复述，并记录为能力证据。

### 应形成的学习资产

- 论文结构卡
- 证据清单
- 限制清单
- 反例/替代解释
- 闭卷复述

### 验收标准

- [ ] 能说明论文的因果或相关边界
- [ ] 引用具体证据支持评价
- [ ] 不把摘要当完整结论

### 异常与恢复

- 论文过难时只聚焦一个图表和一个方法。
- 术语障碍时建立最小术语图，不无限查资料。

### 可复制对话

```text
- 这篇论文真正回答了什么？
- 哪些结论直接由数据支持？
- 请挑战作者最关键的一个假设。
```

## 案例38：文献综述：从资料堆积到研究地图

**适用对象：** 研究生、研究团队  
**建议周期：** 4—8周  
**推荐组合：** `A5+B4+C5+D5`

**案例目标：** 形成主题结构、观点分歧、方法谱系和研究缺口。

### 第一条自然语言

```text
我积累了很多论文，但综述仍像逐篇摘要。请帮我建立问题驱动的文献地图。
```

### 一对一学习契约建议

每周300分钟；每次50分钟；项目式；成功定义为完成有结构、有证据、有缺口判断的综述章节。

### 微习惯配方

```text
当我读一篇新文献，我只判断它在回答哪个问题、用什么证据。
```

### 操作步骤

1. 明确综述范围、时间、纳入与排除标准。
2. 建立研究问题树和文献标签。
3. 按观点、方法、数据、结论和限制建立证据矩阵。
4. 识别共识、争议、空白和重复研究。
5. 写主题段落而非逐篇摘要。

### 应形成的学习资产

- 问题树
- 证据矩阵
- 分歧地图
- 综述章节

### 验收标准

- [ ] 每段围绕问题而非作者列表
- [ ] 缺口由证据支持
- [ ] 纳入标准清晰可复核

### 异常与恢复

- 文献无限增长时启用停止条件。
- 缺口过度夸大时寻找反例和相邻研究。

### 可复制对话

```text
- 把这些文献按研究问题而不是作者分组。
- 找出真正的观点分歧。
- 审查这个“研究空白”是否被夸大。
```

## 案例39：研究问题生成与筛选

**适用对象：** 科研初学者、创新团队  
**建议周期：** 2—6周  
**推荐组合：** `A5+B4+C5+D5`

**案例目标：** 从兴趣领域形成可回答、重要、原创且可行的问题。

### 第一条自然语言

```text
我对AI辅助学习感兴趣，但问题太大。请引导我生成并筛选研究问题。
```

### 一对一学习契约建议

每周180分钟；苏格拉底式；成功定义为形成一个可研究问题、理论定位和可执行验证计划。

### 微习惯配方

```text
当我开始思考选题，我只写一个可观察现象和一个“为什么”。
```

### 操作步骤

1. 区分主题、现象、问题、假设和方法。
2. 生成问题树：描述、解释、预测、干预和设计问题。
3. 用重要性、原创性、可行性、证据可得性、伦理筛选。
4. 导入关键文献验证是否已有答案。
5. 为候选问题写最小研究设计。
6. 选择主问题并记录放弃理由。

### 应形成的学习资产

- 问题树
- 候选评分
- 文献验证
- 最小研究设计
- 选择记录

### 验收标准

- [ ] 问题明确对象、关系和边界
- [ ] 可通过证据回答
- [ ] 方法与问题不倒置

### 异常与恢复

- 问题过宽时限制对象、场景或时间。
- 只有方法没有问题时回到现象与理论。

### 可复制对话

```text
- 把我的主题改写成五类研究问题。
- 按重要性和可行性筛选。
- 这个问题是否已经被文献充分回答？
```

## 案例40：实验设计：从假设到可解释结果

**适用对象：** 科研人员、工程实验团队  
**建议周期：** 4—10周  
**推荐组合：** `A5+B5+C5+D5`

**案例目标：** 设计控制变量、测量、样本、分析和预注册式记录。

### 第一条自然语言

```text
我有一个假设，但不知道如何设计可信实验。请先检查可检验性和混杂因素。
```

### 一对一学习契约建议

每周240分钟；证据优先；成功定义为形成可执行方案、数据字典、分析计划和风险清单。

### 微习惯配方

```text
当我开始实验设计，我先写自变量、因变量和一个可能的混杂因素。
```

### 操作步骤

1. 明确理论机制和可证伪假设。
2. 定义变量、测量、样本和排除标准。
3. 识别混杂、偏差、伦理和数据泄漏风险。
4. 先进行小规模试验和流程演练。
5. 建立分析计划，避免看到数据后随意改变指标。
6. 记录偏离方案、异常和不确定性。

### 应形成的学习资产

- 假设表
- 变量与数据字典
- 风险清单
- 试验记录
- 分析计划

### 验收标准

- [ ] 假设可被结果推翻
- [ ] 测量与理论变量对应
- [ ] 分析计划先于正式结果

### 异常与恢复

- 样本不足时收缩问题或定位为探索性。
- 试验失败时保存失败信息价值。

### 可复制对话

```text
- 检查这个假设是否可证伪。
- 列出可能混杂因素。
- 为正式实验设计一个最小试运行。
```

## 案例42：论文修改：从审稿意见到可追踪修订

**适用对象：** 论文作者、研究团队  
**建议周期：** 2—6周  
**推荐组合：** `A4+B5+C5+D5`

**案例目标：** 把审稿意见分解、验证、修改并形成回应证据。

### 第一条自然语言

```text
我收到了审稿意见。请帮我分类和建立修订计划，但不要替我掩盖无法解决的问题。
```

### 一对一学习契约建议

每周240分钟；项目式；成功定义为每条意见有明确处理、证据和回应。

### 微习惯配方

```text
当我打开审稿意见，我只处理一条并写“理解—行动—证据”。
```

### 操作步骤

1. 导入审稿意见和论文版本。
2. 分类为澄清、补分析、补实验、重写、范围争议或无法满足。
3. 为每条意见建立任务、风险和验收标准。

### 应形成的学习资产

- 审稿意见矩阵
- 修订任务
- 版本证据
- 回应信
- 一致性审查

### 验收标准

- [ ] 每条意见都可追踪
- [ ] 论文正文与回应一致
- [ ] 没有夸大已解决程度

### 异常与恢复

- 意见冲突时明确权衡和编辑政策。
- 新增分析影响其他章节时做全局一致性检查。

### 可复制对话

```text
- 把审稿意见分类并排序。
- 这条意见需要什么证据才算解决？
- 检查回应信是否与正文一致。
```

# 附录H：案例实施安全边界

## 数据与隐私

- 只导入自己有权使用的文件。
- 不把API密钥、密码、令牌和隐私数据写入聊天内容。
- 敏感资料优先使用脱敏副本。
- 导出文件默认不应包含模型密钥。

## 高风险领域

- 医疗案例只用于概念学习，不替代医生诊断和治疗。
- 法律案例只用于教育性阅读，不替代律师意见。
- 金融案例只用于知识训练，不构成投资建议。
- 网络安全实验只在合法授权环境中进行。
- 电气、机械、化学和实验操作应遵循专业安全规范。

## 智能体执行

- 高风险写入、删除、迁移、恢复和外部操作应使用B5审批。
- 先在测试数据、测试目标或沙箱环境中演练。
- 重要升级前执行数据库完整性检查、手动备份和JSON/Markdown导出。
- 模型失败时允许明确失败，不应伪造完成结果。

## 教育与反依赖

- AI生成文本不能自动成为学习者能力证据。
- 微习惯完成不能自动证明知识掌握。
- 连续天数不能替代独立性、保持、迁移和作品。
- 对未成年学习者，应由监护人或教师决定隐私、账号、内容和高风险功能边界。
