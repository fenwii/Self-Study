# Self-Study AI V0.6 自然简洁交互

## 1. 设计目标

界面不模仿传统后台管理系统，也不通过大量仪表盘制造复杂感。产品遵循四个原则：

1. **目标即会话**：用户围绕长期目标自然交流；
2. **一次一个动作**：持续突出当前唯一下一步；
3. **渐进披露**：路径、证据、模型与CHART配置按需展开；
4. **长期不打扰**：草稿、位置和上下文自动恢复，减少重复操作。

这里所说的“张小龙式简洁”是产品设计原则上的克制、自然和少即是多，不复制任何具体产品的受保护界面。

## 2. 默认布局

```text
┌──────────────┬─────────────────────────────────────┐
│ 目标会话      │ 当前目标聊天                         │
│ 新建/搜索     │ 标题、下一步、消息、输入             │
└──────────────┴─────────────────────────────────────┘
                         ↘ 进度抽屉按需打开
```

- 左栏宽度236px；
- 主聊天占据剩余空间；
- Inspector默认关闭，打开后成为318px抽屉；
- 专注模式隐藏左右区域；
- 窄屏下Inspector以覆盖抽屉出现。

## 3. 目标会话操作

每个目标会话支持：

- 置顶与取消置顶；
- 就地重命名；
- 归档与恢复；
- 最近打开排序；
- 独立消息搜索；
- 独立草稿保存；
- 独立聊天、路径、任务、复习、资料、评估、作品和证据。

归档是生命周期状态变化，不是删除。归档后所有记录继续保留；恢复后继续原目标。

## 4. 输入框

- 根据内容自动伸缩，最大高度220px；
- `Enter`发送；
- `Shift+Enter`换行；
- 切换目标前后自动保存并恢复各自草稿；
- 发送成功时清空当前会话草稿，不影响其他目标；
- 支持Markdown和LaTeX；
- 失败时保留最后发送内容并提供重试。

草稿保存采用前端即时状态更新加450ms防抖持久化。这样切换目标时界面立即恢复，Main进程和SQLite提供跨重启持久性。

## 5. 下一步与情境建议

建议优先级：

```text
当前可执行里程碑
→ 到期复习
→ 开放评估
→ 未完成任务
→ C5每日简报
```

界面只将第一项呈现为“下一步”。下方建议按钮最多保留四个，并根据当前目标状态动态变化。

## 6. 快捷键

| 快捷键 | 动作 |
|---|---|
| Ctrl/Cmd+N | 新建目标 |
| Ctrl/Cmd+K | 搜索目标 |
| Ctrl/Cmd+, | 打开设置 |
| Ctrl/Cmd+Shift+F | 切换专注模式 |
| Esc | 退出专注或关闭进度 |

## 7. 状态与恢复

长程Agent状态通过一条紧凑状态条呈现：准备、规划、执行、暂停、等待确认。用户可以暂停、继续或取消。

错误不使用全局弹窗打断，而在当前会话输入区上方显示：

```text
错误摘要 · 重试 · 关闭
```

## 8. 无障碍基础

- 主要按钮和输入具有可访问名称；
- 键盘可完成创建、搜索、发送、关闭和专注切换；
- 颜色不作为唯一状态信号；
- 动画克制，状态同时具有文字说明；
- Markdown标题、表格、代码与数学保留语义结构。

## V0.8 渐进式模块操作

用户仍通过自然语言完成主要学习活动。右侧详情只在需要纠正状态时提供少量直接操作，例如暂停复习、标记误解复发、归档资料或恢复作品。复杂状态不会成为首页导航负担。
