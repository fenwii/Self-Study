# 真实性评估与作品验收

## 为什么不是普通测验

即时选择题容易测到识别记忆，不能证明独立能力。Self-Study AI把评估拆成三个维度：

```text
机制解释 × 迁移与边界 × 误解与验证
```

## 评估工作流

1. 根据当前目标创建开放评估；
2. 学习者一次性独立作答；
3. 保存原始答案而非只保存分数；
4. 生成可解释基线得分和反馈；
5. 达标后保存能力证据；
6. 仍需通过延迟复测或陌生场景迁移确认长期掌握。

## 作品验收

作品采用独立量表：

- 是否有可运行/可阅读成果；
- 是否能解释关键决策；
- 是否存在明确外部证据；
- 是否可复现或可检查；
- 学习者独立贡献是什么。

每次验收生成不可变的ArtifactEvaluation历史，作品状态更新为accepted或review。

## 当前评分边界

V0.4自动评分是确定性基线，用于形成产品闭环和开发验证，不应直接用于高风险教育认证、录取、招聘或法律结论。

生产级后续需要：

- 量表版本管理；
- 多模型盲评；
- 人类导师校准；
- 评审者一致性；
- 反作弊与作者身份；
- 延迟复测；
- 领域专家题库；
- 评分偏差审计。
