# Self-Study AI V1.0.0 CHART A5+B5+C5+D5

## V1.0一对一契约扩展

- **A5**：契约把长期成果、每周时间和自主性目标变成正式完成标准；
- **B5**：`contract.upsert`为中风险持久化操作，`review.weekly`为低风险可重复计算操作；
- **C5**：Context编译契约、最近复盘、自主性差距与下次复盘时间；
- **D5**：保存契约版本、确认时间、周复盘事实、教练判断与调整依据。

正式周复盘遵循：事实优先、一次调整一个变量、不做人格归因、不以连续天数替代能力证据。

## 1. 四轴不是标签

A/B/C/D等级会编译为真实运行策略：

```text
A：自主学习闭环深度
B：执行与权限控制强度
C：长期状态与自适应深度
D：证据、审计和责任治理强度
```

625种基础组合由四个独立等级笛卡尔积形成，并与Intent、Skill、工具、模型和当前学习状态组合为动态运行配置。

## 2. A5：从回答到独立能力

V0.5的A5闭环：

```text
真实目标
→ 独立目标会话
→ 起点诊断
→ 版本化路径
→ 里程碑证据门槛
→ 学习者先尝试
→ 最小提示
→ 本地资料证据
→ 主动练习
→ 独立评估
→ 作品验收
→ 延迟复测
→ 陌生场景迁移
```

A5新增强制原则：

- 目标必须有可验证结果；
- 当前阶段完成后才解锁下一阶段；
- 评估保存学习者原始答案；
- 作品必须经过量表验收；
- 模型输出不能直接成为学习者能力证据；
- 最终指标是独立性、保持和迁移。

## 3. B5：受控桌面执行

B5工具域新增：

```text
path.compile
milestone.complete
resource.search
assessment.create
assessment.submit
artifact.evaluate
```

文件导入不作为模型可自由调用工具：它只能由用户在桌面资料库面板触发系统文件选择器。B5对持久化写入、导出和中高风险动作执行审批、预算、最大步骤和Checkpoint。

## 4. C5：长期自适应

C5 Context按目标严格隔离并包含：

- 当前GoalConversation最近消息；
- active path和当前可用milestone；
- 未完成评估和最近作答；
- 作品验收状态；
- 个人资料库清单；
- 与当前问题相关的本地资料片段；
- 到期复习、误解、认知负荷和学习动量。

下一最佳行动优先级：

```text
继续活跃会话
→ 到期复习
→ 反复误解
→ 当前可用里程碑
→ 待完成评估
→ 高优先任务
→ 首个作品
→ 迁移挑战
```

## 5. D5：来源与责任链

D5记录：

- 目标与Conversation标识；
- 原始自然语言；
- Intent和Skill；
- CHART组合；
- Context摘要；
- 本地资料来源片段；
- Plan和Harness决策；
- 审批；
- 工具输入输出；
- 模型候选、失败、回退和成本；
- 第二模型独立审计；
- AssessmentAttempt；
- ArtifactEvaluation；
- Evidence provenance；
- Checkpoint和最终状态。

Alignment要求回答明确区分：

```text
资料中的事实
模型基于资料的推断
需要进一步验证的结论
建议采取的下一行动
```

## 6. 默认全混合模式

```text
A5 + B5 + C5 + D5
```

适用于长期、重要、需要作品和能力证据的目标。轻量解释可降低A/B/C/D等级，以减少Context、工具、成本和审计负担。

## 7. 目标会话与组合模型

A/B/C/D的运行策略不会跨目标共享可变学习状态。模型供应商、静态Skill和组织策略可以复用，但消息、Context、误解、复习、评估、作品和证据必须按Goal隔离。轻量组合仍遵守这一不变量。

## V0.9行为设计扩展

### A5

A5加入“成果闭环＋行为闭环”：完成最小行动只证明行为发生，不能直接证明能力掌握；能力仍需独立评估、保持、迁移和作品证据。

### B5

新增工具：

```text
behavior.diagnose
habit.design
habit.checkin
```

所有写入限定在当前Goal，经过Zod、IPC、领域服务和SQLite事务。

### C5

C5按目标维护动机、能力、提示可靠性、成功率和最小行动；低能力时优先缩小行为，提示失效时优先更换锚点。

### D5

D5记录配方、行为结果、条件评分、庆祝与调整，但禁止将Check-in自动升级为能力证据。
