# Self-Study AI V1.0.0 正式版发布说明

发布日期：2026-07-30。

## 正式版主题

**从“AI辅助学习工具”升级为“目标隔离的一对一自学操作系统”。**

## 新增

- 一对一学习契约；
- 正式周复盘；
- 目标级自主性状态；
- 行为—学习—成果三层引擎；
- 契约与周复盘的自然语言入口；
- 契约缺失和复盘到期的唯一下一步；
- Schema V10；
- V0.9→V1.0无损迁移；
- 正式发布质量门禁。

## 正式版稳定边界

- 目标独立会话和Context；
- CHART A1–A5/B1–B5/C1–C5/D1–D5组合；
- 九模型供应商控制面；
- Markdown与LaTeX；
- 本地资料、评估、作品和证据；
- 微习惯和福格行为模型；
- SQLite、备份恢复和完整导出。

## 升级提醒

旧V0.9目标不会自动获得契约。升级后进入目标，系统会把“建立一对一学习契约”作为优先下一步，等待用户主动确认。

## 当前交付形式

本包为完整正式版源码。当前构建环境的内部npm代理缺少`@electron-forge/cli@7.8.1`，因此未生成锁文件和签名安装包。正式发布安装包前必须完成`docs/RELEASE_READINESS.md`中的剩余门禁。
