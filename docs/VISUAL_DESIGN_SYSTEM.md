# Self-Study AI V0.7视觉设计系统

## 1. 目标

V0.7不通过增加装饰制造“高级感”，而通过更稳定的文字对比、阅读宽度、空间节奏、层级与可访问性建立长期使用质量。

设计原则：

```text
内容优先
一次突出一个动作
高对比但不刺眼
空间用于建立关系，而不是填满页面
动效只表达状态变化
复杂能力渐进披露
```

## 2. 设计令牌

应用使用统一CSS变量驱动：

- `--canvas`：窗口背景；
- `--surface`：阅读主画布；
- `--surface-subtle`：次级区域；
- `--text-primary/secondary/tertiary`：三级文字；
- `--border-soft/strong`：边界层级；
- `--accent/accent-soft`：唯一主要强调色；
- `--reading-width`：正文阅读宽度；
- `--font-scale`：全局文字倍率；
- `--space-unit`：舒适/紧凑空间倍率。

## 3. 对比度

静态令牌校验结果：

| 场景 | 对比度 |
|---|---:|
| 明亮主题正文/白色 | 17.61:1 |
| 明亮主题次级文字/白色 | 6.75:1 |
| 明亮主题三级文字/白色 | 4.52:1 |
| 明亮主题用户气泡 | 11.41:1 |
| 深色主题正文/主画布 | 15.55:1 |
| 深色主题次级文字/主画布 | 8.94:1 |
| 深色主题用户气泡 | 7.59:1 |

正文和小号辅助文字均以WCAG AA 4.5:1为最低门槛。

## 4. 阅读宽度

用户可选择：

- 专注：720px，适合长文和研究阅读；
- 标准：860px，适合普通学习与公式；
- 宽阔：1040px，适合代码、表格和复杂图谱。

消息、输入框、建议、错误和运行状态使用同一阅读轴，避免视觉跳动。

## 5. 明暗主题

- `system`：跟随操作系统实时变化；
- `light`：固定明亮主题；
- `dark`：固定深色主题。

主题不是简单反色：深色主题单独定义文字、边框、用户气泡、代码区、阴影和状态色。

## 6. 可访问性

实现：

- `:focus-visible`键盘焦点；
- 跳过导航链接；
- 错误`role=alert`；
- Agent状态`aria-live=polite`；
- 系统与应用级减少动态效果；
- 90%—120%文字缩放；
- 增强对比模式；
- 输入框和关键按钮保持足够触控面积。

## 7. 自然空间效果

空间效果只使用三种手段：

1. 画布与阅读面轻微明度差；
2. 浮层使用低透明度双层阴影；
3. 顶部使用极弱环境光，不使用炫目渐变。

主聊天区域保持平整，阴影只用于输入框、菜单和设置浮层。
