# 本地个人资料库

## 设计目标

资料库不是把所有文件无差别发送给模型，而是让学习者拥有、控制并引用自己的长期学习资料。

## 当前支持

- TXT
- Markdown
- JSON
- CSV
- 单文件最大5MB
- 单次最多20个文件
- SHA-256去重
- 本地SQLite分块
- 中英文关键词召回
- 目标级和工作区级资料

## 安全边界

1. 必须由用户点击“导入”并使用系统文件选择器；
2. Renderer不能提供任意路径给Main读取；
3. 只允许白名单文本格式；
4. 不执行导入内容中的脚本、HTML或命令；
5. 默认不上传整个文档；
6. 只有检索命中的必要片段进入当前一次模型Context；
7. 资料不包含模型API密钥和系统Secret。

## 检索策略

当前评分综合：

- 资料标题命中；
- 分块词组出现次数；
- 中文2/3/4字词组；
- 当前Goal作用域；
- 最近更新时间。

此实现可解释、可离线、无第三方向量服务依赖，适合作为V0.4基线。
